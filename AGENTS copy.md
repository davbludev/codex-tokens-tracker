## Commits and pushes

After each completed step, agents are authorized to commit and push the relevant changes without asking for confirmation. Run appropriate checks first, keep commits scoped to the completed work, and use a normal push to the current branch.

## Agent skills

### Issue tracker
Issues and specs live in GitHub Issues. Before tracker operations, read `docs/agents/issue-tracker.md`.

### Triage labels
Use the five default triage labels. Before triaging, read `docs/agents/triage-labels.md`.

### Domain docs
Use a single-context layout. Before exploring the codebase, read `docs/agents/domain.md`.
